# Programadores-Juniors-
Projeto desenvolvido no NotebookLM para criar uma IA generativa que auxilie iniciantes em programação. Utiliza materiais do Curso em Vídeo sobre Algoritmos e JavaScript para ensinar lógica de programação, fundamentos e conceitos essenciais, incentivando o aprendizado prático e o uso consciente da IA como ferramenta de apoio.
